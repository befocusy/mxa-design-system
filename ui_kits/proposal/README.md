# UI Kit — MXA Client Proposal

A high-fidelity recreation of MXA's flagship deliverable: the **client service proposal**, an **A4 portrait** document sent to clients. Rebuilt from the two source proposals (Autodata S.R.L. and the residency-certificate engagement).

## Run
Open `index.html`. The viewer presents the document one A4 page at a time with a page rail, prev/next navigation (or ← →), and the standard MXA toolbar (download / accept actions are cosmetic).

## Pages (`Pages.jsx`)
- **CoverPage** — dark ink cover, white wordmark + tagline, large Ubuntu-bold title, date, client, faint globe motif.
- **LetterPage** — Para/Ref/Fecha meta, the "Estimados…" cover letter, MXA signature block.
- **AntecedentesPage** — background section with a bulleted income list and an "encargo" panel.
- **AlcancePage** — scope: Etapa 1 / Etapa 2 stage cards + an ink "Entregable" card.
- **HonorariosPage** — fee `DataTable` (USD) with the optimization-fee footnote.
- **AnexoPage** — terms & conditions, numbered `ClauseList`.

## Composition
Every page is built from the design-system primitives — `SectionLabel`, `DataTable`, `ClauseList`, `SignatureBlock`, `DocFooter`, `Card`, `Badge`, `Divider` — read from `window.MXADesignSystem_5dc0a4` after the bundle loads. Page layout lives in `proposal.css`; the viewer chrome is `Viewer.jsx`.

## Notes
- Pages are fixed 794×1123px (A4 @96dpi) and scaled to fit the viewport via transform.
- Copy is drawn from the real proposals (formal Rioplatense Spanish, usted).
- The bundle (`../../_ds_bundle.js`) is generated by the compiler; the kit renders once it exists.
