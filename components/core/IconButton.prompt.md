**IconButton** — square, icon-only control for toolbars and table rows. Quiet `ghost` by default.

```jsx
<IconButton label="Descargar" variant="outline"><DownloadIcon/></IconButton>
```

Variants: `ghost | outline | solid`. Sizes `sm | md | lg`. Always pass `label` for accessibility. Use Lucide icons (1.5–2px stroke) as children.
